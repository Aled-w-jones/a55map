Privacy

This is a personal hobby site that shows public CCTV feeds operated by Traffic Wales on the A55. It is provided as-is, with no warranty.

What this site does not do

  • It does not set any cookies.
  • It does not ask for your location, name, email, or any other personal information.
  • It does not have user accounts or logins.
  • It does not store anything about you on a server. There is no server-side component — the site is static files only.

Third parties your browser contacts when you load the site

Like any web page, your browser makes requests to fetch the resources the page is built from. Each of those parties may log your IP address and request metadata for their own purposes, under their own privacy policies:

  • GitHub Pages — hosts the site. Privacy statement.
  • Esri (ArcGIS) — loads the map library and basemap tiles. Privacy overview.
  • Traffic Wales — serves the camera images, hotlinked from members.traffic.wales. Privacy policy.
  • Cloudflare Web Analytics — anonymous page-view metrics (no cookies, no cross-site tracking). Product page.

Contact

The source for the public build of this site lives on GitHub. If you have a concern, open an issue there.
